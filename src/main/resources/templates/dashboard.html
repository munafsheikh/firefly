🔥 Firefly — Plugin-Powered Spring Boot Platform

Version 0.0.1-SNAPSHOT — Extensible app with web API, CLI, terminal, and Model Context Protocol integration

🚀 What Can You Do?

  • 📡 Explore the REST API: Full OpenAPI/Swagger documentation with interactive testing at /swagger-ui.html
  • 💻 Web Terminal: SSH-like terminal interface in your browser at /terminal (powered by xterm.js + pty4j)
  • 📊 System Health: Real-time health, metrics, and info via Spring Actuator endpoints at /actuator
  • 🔧 Extensible Architecture: Drop new plugin JARs into plugins/ — they auto-load with zero server restart
  • 🧠 Model Context Protocol (MCP): Embedded MCP server exposes tools for AI agents (list plugins, health checks, actuator data, endpoints)
