WebTUI Browser

A scoped-down "browsing with images/JS/CSS in a terminal-like UI" MVP: real headless Chromium rendered to a screenshot, not a full remote-desktop protocol.

Headless Chromium isn't available in this environment, so the WebTUI Browser can't actually render pages here. The plugin has degraded gracefully instead of crashing — the API still responds, but navigation, clicking, scrolling, and typing are disabled until a working Chromium install is present.
